# Default Configuration Templates

This directory holds default configuration templates for `ptx-codeinfo`, in the same
way as `codeanalysis/defaults/` does for `ptx-codeanalysis`.

`ptx-codeinfo` has no configuration file yet: the `loc` command takes all its input
from command line arguments. Templates are added here when a command gets
configuration options (for example include and exclude patterns for directory
analysis).
